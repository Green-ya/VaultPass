# 🔐 VaultPass

**Версия 0.2.0 (в разработке; базовая — 0.1.0 MVP)**

VaultPass — настольный GUI-менеджер паролей для HashiCorp Vault (KV v2).

Вдохновлён KeePass, но работает с корпоративным Vault: подключается по токену и
даёт удобный доступ к секретам без консоли и `vault kv get`.

## ✨ Возможности

- Подключение к Vault по токену, выбор mount point
- Древовидная структура каталогов с ленивой загрузкой
- Правая панель без вкладок: выбор каталога или секрета в дереве сразу показывает его содержимое
- Активный элемент подсвечен в дереве и отображается в заголовке правой панели
- Просмотр секретов с несколькими ключами
- Маскирование значений с индивидуальным переключателем-глазом в каждой строке
- Копирование значения двойным кликом, по `Ctrl+C` и через контекстное меню
- Глобальный поиск `Ctrl+F` по путям, а по желанию — по ключам и значениям
- Создание, редактирование и удаление секретов; при создании путь активного каталога подставляется автоматически
- Контекстное меню в дереве: открыть, создать секрет здесь, переименовать, удалить, обновить
- Единая кнопка удаления в правой панели с подтверждением вводом имени секрета
- Генератор паролей с настройкой длины и наборов символов
- Ненавязчивые уведомления в статусной строке вместо модальных окон (модальные — только для разрушающих действий)
- Автоочистка буфера обмена через 30 секунд с обратным отсчётом
- Явное отключение от Vault с очисткой токена, кэша секретов и буфера обмена
- Шифрованное хранение токена в `~/.config/vaultpass/`

## 🔒 Безопасность

- Токен шифруется Fernet-ключом.
- Ключ хранится в системном keyring (GNOME Keyring / KWallet / macOS Keychain), если он доступен.
- Если keyring недоступен, ключ сохраняется в файл с правами `0600`, а каталог — `0700`.
- Старый каталог `~/.config/vault-manager` автоматически мигрирует при первом запуске.
- Значения никогда не выводятся в статусную строку; буфер обмена очищается автоматически.
- Буфер обмена очищается и при закрытии окна; расшифрованные секреты вычищаются из памяти при отключении, по таймеру и при выходе.
- Удаление требует подтверждения вводом имени секрета и удаляет все его версии в KV v2.
- В лог пишутся только технические детали (пути, типы ошибок), но не значения секретов и не токен.

## 🩺 Логи

Технические детали ошибок пишутся в файл с ротацией:

```
~/.config/vaultpass/vaultpass.log
```

Для подробного лога (уровень DEBUG) запустите с переменной окружения
`VAULTPASS_DEBUG=1` или включите «Вид → Режим отладки» во время работы.

## 🚀 Установка и запуск

```bash
git clone https://github.com/Green-ya/VaultPass.git
cd VaultPass

python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt

python main.py
```

Или через `./run.sh`.

### вариант для nix
```bash
nix run github:Green-ya/VaultPass
```
или для добавления в конфигурацию
```flake.nix
inputs = {
  vaultpass.url = "github:Green-ya/VaultPassNix";
};
```
```configuration.nix
environment.systemPackages = [
  inputs.vaultpass.packages.${pkgs.system}.default
];
```

## 🧭 Быстрый старт

1. Нажмите «🔑 Подключиться» и укажите URL, токен и mount point (обычно `secret`).
2. Кликните по папке в дереве — её содержимое появится справа; стрелка раскрывает вложенные каталоги.
3. Кликните по секрету — справа откроются его ключи и значения.
4. Двойной клик по значению копирует его в буфер обмена; то же делает `Ctrl+C` для выделенной строки.
5. Иконка глаза в конце строки показывает или скрывает только это значение; перечёркнутый глаз означает, что значение открыто.
6. `Ctrl+F` открывает глобальный поиск. Для поиска по ключам и значениям включите соответствующую опцию — это медленнее, так как читает каждый секрет.
7. Кнопка «➕ Новый секрет» создаёт секрет (путь активного каталога подставляется автоматически), `Ctrl+Shift+Enter` сохраняет в диалоге, «✏️ Изменить» на панели секрета — редактирует.
8. Правый клик по узлу дерева открывает меню: открыть, создать секрет здесь, переименовать (только секреты), удалить, обновить.
9. Кнопка «🗑️ Удалить» в нижней части правой панели удаляет выбранный секрет. Для подтверждения нужно ввести имя секрета в отдельном окне.
10. «🔌 Отключиться» (или `Ctrl+Shift+D`) завершает сессию и очищает память и буфер обмена.

## 🧪 Тесты

```bash
pip install -r requirements-dev.txt
pytest -q
```

Тесты не требуют реального Vault и запускают Qt в режиме `offscreen`
(сейчас — 98 тестов). В CI (`GitHub Actions`) прогоняются `pylint` и `pytest`
на Python 3.11 и 3.12.

## 📦 Сборка AppImage

```bash
./build_appimage.sh
```

Скрипт использует `vaultpass.spec`, собирает `dist/vaultpass`, проверяет наличие локальных модулей в архиве и упаковывает приложение в `VaultPass-x86_64.AppImage`. Готовый AppImage лежит в разделе [Releases](../../releases).
