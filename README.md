# 🔐 VaultPass

VaultPass — это простой и удобный GUI-менеджер паролей для HashiCorp Vault.

Вдохновлён KeePass, но работает с корпоративным Vault.

## ✨ Особенности

- Подключение к Vault по токену
- Древовидная структура каталогов
- Вкладки для удобной навигации
- Просмотр секретов с несколькими ключами
- Копирование значений одним кликом
- Шифрованное хранение токена в `~/.config/vaultpass/`
- Создание и обновление секретов

## 🚀 Установка и запуск 

```bash
# Клонируем
git clone https://github.com/yourusername/VaultPass.git
cd VaultPass

# Создаём виртуальное окружение
python3 -m venv venv
source venv/bin/activate

# Устанавливаем зависимости
pip install -r requirements.txt

# Запускаем
python main.py
```
